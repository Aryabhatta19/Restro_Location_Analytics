# Restro_Location_Analytics
This project analyzes restaurant data to uncover insights about customer preferences, restaurant ratings, and the impact of online orders and table bookings.
It uses Python-based data visualization and analysis to identify trends that can help improve restaurant business strategies.
Key Insights:
          Restaurants offering online orders or table booking tend to have higher average ratings.
          Certain locations and cuisines show significantly better engagement metrics.
          Visual trends highlight customer preferences and pricing patterns across city regions.

/kaggle/input/zomato-bangalore-restaurants/zomato
The dataset used: /kaggle/input/zomato-bangalore-restaurants/zomato
It contains features such as:
    Restaurant name and location
    Type of cuisine and price range
    Online ordering and table booking availability
    Customer ratings and votes
