# Restro_Location_Analytics
This project analyzes restaurant data to uncover insights about customer preferences, restaurant ratings, and the impact of online orders and table bookings.
It uses Python-based data visualization and analysis to identify trends that can help improve restaurant business strategies.
Key Insights:
          1) Restaurants offering online orders or table booking tend to have higher average ratings.
          2) Certain locations and cuisines show significantly better engagement metrics.
          3) Visual trends highlight customer preferences and pricing patterns across city regions.

The dataset used: /kaggle/input/zomato-bangalore-restaurants/zomato
It contains features such as:
1) Restaurant name and location
2) Type of cuisine and price range
3) Online ordering and table booking availability
4) Customer ratings and votes
